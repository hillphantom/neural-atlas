# Contributing

Keep changes focused and include a short explanation and verification steps.
Run `node test.cjs` and check the affected views in a browser.

Use fictional fixtures in issues, tests and pull requests. Do not upload credentials,
private telemetry, personal paths or internal machine addresses. Keep activity.json
as an empty array in commits; keep real feeds outside version control.

Preserve the distinction between simulation, reported events and verified results.
Do not infer completion from elapsed time. Keep rendering and retained history bounded.

Contributions are provided under the repository's MIT license.
